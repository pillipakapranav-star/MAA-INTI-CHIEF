# 🥘 MAA-INTI-CHIEF (Maa Chief Kitchen)

> **ADVANCE RESTAURANT – Homestyle Gourmet Dining, Executive Chief Kitchen Line & Multi-Currency Experience**

A state-of-the-art, multi-role restaurant web application connecting diners, executive kitchen chefs, and restaurant owners in real-time.

---

## ✨ Features

- **🍽️ Guest Dining Portal:**
  - Interactive artisan menu with categories (Mains, Grill, Oven, Starters, Desserts, Mocktails).
  - Multi-Currency Conversion Engine (USD, EUR, GBP, INR, JPY, AED, CAD, AUD, CHF, SGD).
  - Dynamic Bag & Checkout with promo codes (`GOURMET15`), delivery options, and tip calculator.
  - Interactive dish details modal with dietary and allergen info.

- **👨‍🍳 Chief Kitchen Line (KDS):**
  - Live kitchen tickets with status transitions (New Ticket ➔ In Prep ➔ Fired/Sauté ➔ Plated ➔ Completed).
  - Station routing (Grill, Wok, Sauté, Oven, Pastry, Fryer).
  - Pantry inventory tracking with restock & reserve levels.
  - Live order simulation (`+ Order`).

- **👑 Owner Suite:**
  - Business analytics, real-time revenue stats, table turnover rates.
  - Interactive table management and staff roster status.
  - Operational metrics and live performance tracking.

- **🎨 Aesthetics & System:**
  - Multiple curated theme palettes (Aurora Cyber, Sunset Bistro, Neon Night, Emerald Garden).
  - Web Audio sound effects and chimes for user interactions.
  - HTML5 Canvas celebration confetti physics.
  - Live Kitchen Operations clock and adaptive metrics banner.

## 🚀 Getting Started

### 1. Prerequisites
Ensure [Node.js](https://nodejs.org/) (v16+) is installed.

### 2. Installation
```bash
npm install
```

### 3. Running Locally
```bash
npm start
```
The application will launch at:
```
http://localhost:3000
```

## 🛠️ Tech Stack
- **Frontend:** Semantic HTML5, Vanilla JavaScript (ES6+), Vanilla CSS (Custom Design System with Glassmorphism, CSS Variables, and Keyframe Animations).
- **Backend:** Node.js, Express.js.
